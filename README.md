# 🎨 SkillMatch Criativo — Gestão de Oportunidades para Designers

Plataforma de mapeamento dinâmico e diagnóstico de portfólios desenvolvida em **HTML5**, **CSS3** e **JavaScript Vanilla (Módulos ES)** para o processo de avaliação prática.

## 🚀 Funcionalidades Técnicas
- Modelagem de negócios modularizada via EcmaScript Modules.
- Algoritmo de aderência regional baseado em Programação Orientada a Objetos com Herança.
- Tratamento reativo de dados locais consumidos via `fetch` assíncrono.
- Persistência das preferências profissionais baseada no `localStorage`.
